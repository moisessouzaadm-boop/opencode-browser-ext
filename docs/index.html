OpenCode Browser

Extensão Chrome (MV3) que liga o OpenCode às suas abas reais: snapshot, clique, digitação, screenshot e mais — via @browsermcp/mcp. Grátis, open-source (MIT), sem coleta de dados.

GitHub Download (.zip/.crx)

Instalar em 3 passos

1. chrome://extensions → modo desenvolvedor → Carregar sem compactação → extension/dist/
2. Adicione o bloco "browsermcp" no seu opencode.jsonc (ver README)
3. Foque uma aba http(s), clique no ícone, chame browser_snapshot

Auto-update sem loja

Via policy gerenciada + GitHub Pages. Guia completo em docs/updates.md.

Privacidade: coletamos nada.
