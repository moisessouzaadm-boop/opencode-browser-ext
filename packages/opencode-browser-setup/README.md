# opencode-browser-setup

> Independent community project — not built by or affiliated with the [OpenCode](https://opencode.ai) team.

Setup helper for [OpenCode Browser](../..). Validates your environment and prints the exact `browsermcp` MCP block for `opencode.jsonc`.

```bash
npx opencode-browser-setup
```

No telemetry, no network calls — everything stays local (see root `PRIVACY.md`).
